# Plan de pruebas

Se añadirán pruebas junto con el código de cada módulo:

- Clasificación: límites calibrados, valores inválidos, sensor ausente y datos caducados.
- SQLite: inserción, recuperación e historial ordenado con base temporal.
- API: JSON, códigos HTTP y estados no disponibles con sensores simulados explícitos.
- Integración física: lectura de humedad, LCD, LED, buzzer y botón en la Raspberry.

Las simulaciones no sustituyen la calibración ni las pruebas de hardware.
No hay pruebas de un MVP implementado todavía.
